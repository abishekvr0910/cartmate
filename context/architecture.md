**Activity contract (2026-10-14):** `ActivityCategory` now includes study, fitness, walk, food and social alongside existing shopping/venue categories. Stored legacy enum values are unchanged; the frontend reads labels/icons from one category catalog. A trip plan stores an optional `meeting_point` for backwards compatibility; plans for the new categories require a specific point before the host can propose them, and the agreed point becomes the trip rendezvous text. The server does not verify that a free-text venue is genuinely public/open. `no_expected_spend` requires a zero estimated cost, and either participant must still accept every changed plan. The Jev classifier is advisory only. Uvicorn log records redact one-use WebSocket ticket query values; review reverse-proxy/access-log policy separately before EC2 launch.

**Historical implementation snapshot (2026-10-12):** Recovery closes old sockets with code 1008; broadcast/user-send paths drop revoked frames; recovery persistence failure rolls back atomically permitting same-code retry. Prior suites passed 157 backend/DR, 12 preflight, 16 browser cases and five probes. Current evidence and residual findings supersede this snapshot above.

Current deployed-style auth is carrier-backed six-digit SMS OTP with cryptographic sessions, one-use invitations and server authorization. `phone_verified_at` means an actual phone OTP succeeded. Staging/production reject development console OTP and demo sessions. In staging mode (`CARTMATE_ENV=staging`), closed-pilot operator admission (`operator_in_person` assurance marker via Migration 9) is implemented without SMS, leaving `phone_verified_at` as NULL, with atomic redemption, fault-tolerant rollback, single-use `CMREC-...` account recovery (Migration 10), and witnessed in-person adult attestation (`physical_identity_document` / `mdowod_qr`). Production has no trusted age provider and stays fail-closed.

The zero-cost delivery boundary is a local FastAPI process bound to loopback, a persistent SQLite file on the founder's computer, and private HTTPS sharing to invited devices (Tailscale Serve). Local code/harness and runbook exist, but **actual private sharing and physical-device access are not verified**. Verify exact HTTPS Origin, same-origin `/api` and `/ws`, no direct public backend port, access-control membership and computer uptime before use. A free Render web service is not a replacement for the SQLite disk because its filesystem is ephemeral. GitHub stores source, not a working application.

Safety invariants: live social REST and WebSockets require current 18+ approval, confirmed pilot membership, active account and object-level authorization; a block removes mutual discovery/contact/chat access; SOS is direct voice `tel:112` only; no third-party ID document data enters CartMate; location shared to discovery remains coarse. Operator actions need an auditable actor and no self-approval. Backup must be restorable and kept off the host for an actual pilot, subject to a privacy review.

External-service status: no GitHub remote, valid GitHub login, live SMS account, Render service, Tailscale installation, hosted URL or off-device recovery has been verified. Do not silently assume any exist.
